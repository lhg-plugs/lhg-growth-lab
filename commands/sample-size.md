# /lhg-growth-lab:sample-size —— 样本量估算

用户输入在 `$ARGUMENTS` 中：`--p1 <基线转化率> --mde <最小可检测效应> [--power 0.8] [--alpha 0.05]`。
`--mde` 默认为**相对提升**（如 0.2 = +20%）；要按绝对差值算，加 `--absolute 0.03`。

## 流程

### 1. 拿参数（缺的就问，最多 2 个问题）
- 基线转化率 p1（不知道就先跑 1~2 周测基线，不许编）
- 最小可检测效应：你**在乎**的最小提升是多少？（不是"期望"提升，是"低于这个就不值得做"的线）
- 可选：功效默认 0.8、显著性水平默认 0.05（小白不用改）

### 2. 跑脚本
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/ab_stats.py samplesize --p1 <p1> --mde <mde> --format text
```

### 3. 解读与折算
1. 输出每组所需样本 N；总样本 2N。
2. 按用户日流量折算：天数 = 2N / 日流量，向上取整；**天数 <7 则按 7 天算**（消除星期效应）。
3. 给诚实结论：
   - 天数 ≤ 用户可接受周期 → "可以做，跑 X 天"
   - 天数太长（如 >8 周）→ "流量不够，三个选择：① 提高 MDE（只测大变化）② 只做单组前后对比 ③ 先涨流量再做实验"，不许硬做

## 硬规则
- MDE 不许事后调小（"测不出来就把 MDE 改小重算" = 作弊）。
- 基线不知道不许编：先测基线，或按"无基线，先跑 2 周"处理。
- 样本量是"每组"不是"总共"：跟用户讲清楚要乘以 2。

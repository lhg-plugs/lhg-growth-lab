# /lhg-growth-lab:ab-significance —— 显著性判定

用户输入在 `$ARGUMENTS` 中，二选一：
- 转化率类：`--x1 <对照组转化数> --n1 <对照组样本> --x2 <实验组转化数> --n2 <实验组样本>`
- 均值类：`--mean1 <均值> --sd1 <标准差> --n1 <样本> --mean2 <均值> --sd2 <标准差> --n2 <样本>`

加载 skill `lhg-gl-stats` 全程指导解读。

## 流程

### 1. 先做资格检查（跑脚本前）
- [ ] 样本量达到当初估算的 N 了吗？（没达标 → 先说"样本不够，结论不可信"，不许直接算 p 值交差）
- [ ] 周期跑满了吗？（提前停 → 标"提前停止，结果可能虚高"）
- [ ] 分流比例正常吗？（如 50/50 设计，结果 70/30 → 先查 SRM 分流异常，不谈显著性）
- [ ] 口径与实验方案一致吗？（换了口径 → 结论作废）

任一项不过 → 先处理，不许跳过。

### 2. 跑脚本
```bash
# 转化率类
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/ab_stats.py ztest --x1 <x1> --n1 <n1> --x2 <x2> --n2 <n2> --format text
# 均值类
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/ab_stats.py ttest --mean1 <m1> --sd1 <s1> --n1 <n1> --mean2 <m2> --sd2 <s2> --n2 <n2> --format text
# 多个指标同时判定
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/ab_stats.py bonferroni --p "<p1>,<p2>,<p3>" --format text
```

### 3. 解读（按 lhg-gl-stats 第 4 节）
1. 报 p 值 + 结论：p<0.05 → "显著，差异不太可能是运气"；p≥0.05 → "不显著，当前数据不足以排除运气"。
2. 报提升幅度 + 95% 置信区间：**显著 ≠ 值得做**——提升 0.1% 即使显著，业务价值也可能为负（开发成本）。
3. 下最终结论三选一：**采纳**（显著且提升有业务价值）/ **放弃**（不显著或提升无价值）/ **继续跑**（接近显著但样本未达标——注意：不是"再看看"，是"样本不够，补到 N 再判定"）。

### 4. 输出判定报告
存 `docs/gl-significance-YYYYMMDD.md`：输入数据 / 资格检查 / 脚本输出 / 解读 / 结论。

## 硬规则
- 样本未达标就谈 p 值 → 不许，先说样本不够。
- p=0.06 说成"边缘显著，算赢" → 不许；0.05 就是线，过了就是没过。
- 显著但提升微小 → 结论必须写"统计显著、业务价值有限"，不许只报"显著"。
- 多个指标只报显著的那个 → p-hacking；要么 Bonferroni 校正，要么全报。
